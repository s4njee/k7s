# Supported Resource Matrix

k7s provides specialized views, status parsing, column sets, and context actions for 31+ built-in Kubernetes resource kinds, in addition to lazy CRD discovery.

---

## Resource Kinds Matrix

| Kind | Group | Table Columns | Supported Actions |
|---|---|---|---|
| **Pods** | Workloads | `NAME`, `NAMESPACE`, `READY`, `RESTARTS`, `CPU`, `MEM`, `AGE`, `STATUS` | Logs, Shell, Port-Forward, Delete, Restart |
| **Deployments** | Workloads | `NAME`, `NAMESPACE`, `READY`, `UP-TO-DATE`, `AVAILABLE`, `AGE` | Scale, Rollout Restart, Rollout Undo, Delete |
| **StatefulSets** | Workloads | `NAME`, `NAMESPACE`, `READY`, `AGE` | Scale, Rollout Restart, Rollout Undo, Delete |
| **DaemonSets** | Workloads | `NAME`, `NAMESPACE`, `DESIRED`, `CURRENT`, `READY`, `UP-TO-DATE`, `AVAILABLE`, `NODE SELECTOR`, `AGE` | Rollout Restart, Rollout Undo, Delete |
| **Jobs** | Workloads | `NAME`, `NAMESPACE`, `COMPLETIONS`, `DURATION`, `AGE`, `STATUS` | Delete, Re-run |
| **CronJobs** | Workloads | `NAME`, `NAMESPACE`, `SCHEDULE`, `SUSPEND`, `ACTIVE`, `LAST SCHEDULE`, `AGE` | Trigger Job Now, Suspend/Resume, Delete |
| **ReplicaSets** | Workloads | `NAME`, `NAMESPACE`, `DESIRED`, `CURRENT`, `READY`, `AGE` | Scale, Delete |
| **Services** | Network | `NAME`, `NAMESPACE`, `TYPE`, `CLUSTER-IP`, `EXTERNAL-IP`, `PORTS`, `AGE` | Port-Forward, Delete |
| **Ingresses** | Network | `NAME`, `NAMESPACE`, `CLASS`, `HOSTS`, `ADDRESS`, `PORTS`, `AGE` | Delete |

| **CRDs** | Cluster | `NAME`, `GROUP`, `VERSION`, `SCOPE`, `AGE` | Open Lazy View |
