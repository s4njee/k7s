# k7s — Kubernetes Visual Monitor

**k7s** is a fast, keyboard-light, single-window **Kubernetes visual monitor** in the spirit of Lens, built as a desktop application with a high-performance **Rust backend (Tauri v2)** and a **React 19 + TypeScript** frontend.

Designed from the ground up for high fidelity, instant responsiveness, zero telemetry, and deep cluster inspection, k7s delivers the rich visual ergonomics of modern desktop tools while preserving the raw control and speed required by DevOps and SRE teams.

## Key Capabilities at a Glance

- **Multi-Cluster Rail**: Switch between dozens of clusters instantly without teardown. Connect multiple kubeconfig files, view aggregated problem summaries, and export context QR codes for mobile sync (`mk7s`).
- **Comprehensive Catalog**: 31+ built-in kinds across Workloads, Network, Config, Storage, Cluster, and RBAC, plus dynamic **Custom Resource Definition (CRD)** lazy discovery with `additionalPrinterColumns`.
- **Relationship Graph & Properties**: Deep "what is this wired to" relationship resolution. Pods link to ReplicaSets and Deployments, PVCs resolve to PVs, Secrets redact credentials safely, and Helm releases show full revision histories.
- **Root Node Debug Shell**: Launch an interactive privileged debug pod that `nsenter`s directly into the host namespaces with an explicit consent gate and auto-expiring deadline.
- **Port-Forwarding Hub**: Manage pod and service forwards with reconnect presets, live status indicators, and one-click browser launch.
- **Helm Release Management**: Inspect releases decoded directly from storage Secrets, view values, diff revisions, and execute safe rollbacks or uninstalls.
- **Safe Operations**: Eviction-based node drains that calculate PodDisruptionBudgets (PDBs) before execution, workload rollout restarts and undos, and bulk actions.
- **Offline & Self-Contained**: Bundled fonts (IBM Plex Sans, JetBrains Mono), local design tokens, and instant theme switching (Dark / Light / System).
